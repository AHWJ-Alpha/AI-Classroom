# AI Classroom 3.0.0

## Highlights

- 极简扁平化课堂首页：顶部显示浅色日期，中部保留输入框。
- 默认界面统一为低饱和灰蓝色，减少高亮色、重复卡片和厚重阴影。
- 第一轮主课堂对话完成后，自动生成课堂短名称和一句话简介。
- 名称与简介可在右滑课堂菜单中分别点击并自定义修改。
- 保留长时世界书、长期记忆、章节索引、知识库、分支课堂、人格优先级和本地保存链路。
- 加强 author_private / character_private 的视角隔离提醒，降低角色知识泄露风险。
- 保留多模型 fallback、Vision、TTS 与考试工具。

## Compatibility

- 旧课堂数据可继续加载，新增课堂简介字段向后兼容。
- 本附件为未签名 Release APK，适合测试或自行签名发布。
