# AI Classroom 3.0.0

这是 AI Classroom 的 3.0 正式版本，重点回到安静、清晰、适合长期学习的课堂体验。

## 主要更新

- **极简课堂首页**：移除重复课堂名、星期、标语、装饰图标和多层欢迎卡片，仅保留浅色日期与居中的输入框。
- **统一低饱和主题**：默认界面采用中性灰蓝色，降低高亮色、厚重阴影和过多边框带来的视觉干扰。
- **自动生成课堂身份**：完成第一轮主课堂对话后，自动生成一个简短课堂名称和一句话简介。
- **名称与简介可编辑**：在右滑课堂菜单中，课堂名称和简介可以分别点击、自定义和保存。
- **长期课堂连续性**：继续保留长时世界书、章节索引、长期记忆卡、知识库、分支课堂、人格优先级和本地保存。
- **更清晰的视角边界**：强化 `author_private` 与 `character_private` 的使用规则，减少私密信息被未知角色直接利用的风险。
- **完整功能延续**：保留多模型 fallback、Vision、TTS、考试工具和图片分析能力。

## 兼容性与数据

- 旧版本课堂数据可以继续加载。
- 新增课堂简介字段采用向后兼容方式保存，不会影响已有对话、世界书、知识库和记忆数据。
- 所有课堂、分支、设置、知识库和长期记忆仍默认保存在设备本地。

## 安装说明

下载下方的 `AI-Classroom-3.0.0-release-unsigned.apk` 进行安装。

该 APK 为未签名 Release 构建，适合测试和个人使用。如果设备提示无法安装，请使用 Android Studio 或其他签名工具签名后再安装。

首次使用时，请进入“设置 → 模型模块”，填写兼容 OpenAI API 的 Base URL、API Key 和模型名称。

## 已知提示

- 应用需要可用的模型 API 才能生成课堂回答、自动命名和长期记忆摘要。
- 自动命名失败不会影响正常对话，应用会使用本地保底名称和简介。
