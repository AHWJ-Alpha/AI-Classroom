# AI-Classroom 4.0.1（正式版）

4.0.0 的收尾版本：把交互反馈补完整、输入框收窄、音乐首次使用不再卡在权限上。版本号 `42 / 4.0.1`。

> 4.0.0 为 beta，建议直接使用本版。

## 触感反馈

设置里新增「触感反馈」卡片，滑条调档：**关闭 / 轻 / 中 / 强 / 极大**。
滑到哪一档，就用那一档的强度震一次，直接对比手感。

实现上改用系统调校过的震动基元（`VibrationEffect.Composition`），不再用长脉冲硬拉 ——
线性马达上给的是干脆的一下，而不是嗡嗡的转子感。

| 操作 | 反馈 |
| --- | --- |
| 点按 | 完整一记 |
| 滚动列表 | 全程安静 |
| 拖底栏换位 / 拖滑条 | 每跨一格一记 |

## 输入框

- 平时只占一行，点进去编辑时才变两行，点别处自动缩回。
- 模型与推理合并成一个键，和发送键同一条中心线。
- 输入卡片内边距收紧，整体矮了一截。

## 音乐

- 第一次点音乐按钮若还没给「通知使用权」，直接弹窗说明并给直达按钮，不用自己去系统设置里翻。
- 浮窗、封面、歌名、进度、播放控制均已验证可用。

## 全屏键

- 右上角悬浮键改为圆形，样式与「回到顶部」按钮一致。

## 修复

- 输入框点别处不收起。

## 安装

- Android 8.0（API 26）及以上
- 与 4.0.0 / 3.3.5 签名一致，可直接覆盖安装，数据保留
