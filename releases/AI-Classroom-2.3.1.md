# AI Classroom 2.3.1

本版本优化主课堂初始界面，让刚进入应用或新建课堂时更像 DeepSeek / GPT App 的主界面，并能在开课前快速选择深度思考模型。

## 更新内容

- 空课堂首页显示大字号日期和星期。
- 首页第二行会优先调用用户配置的 API 模型生成一句简短中文学习格言，失败时使用本地格言兜底。
- 开课前输入框上移，减少界面空白感。
- 开课前可选择是否启用深度思考模型，设置会立即保存到当前课堂。
- 用户发送第一条学习要求后，自动进入原先的主课堂对话界面。

## 安装说明

下载 `ai-classroom-2.3.1-debug.apk` 后安装即可。升级安装会保留本地课堂、分支、知识库、记忆和设置数据。
