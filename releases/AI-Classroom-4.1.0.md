# AI Classroom 4.1.0：课堂与对话联动

发布日期：待定　｜　versionCode 47　｜　versionName 4.1.0

这一版把「课堂」从独立工作区改成**每个对话自己的长内容工作区**：从主对话滑入，用该对话的模型、人格、角色卡与资料连续生成教学或小说内容，结果回到原对话，并可从对话继续讨论与阅读。

## 新的

- **项目归属对话**：课堂项目绑定创建它的对话，规划、生成、重写、同步都按项目自己的来源解析配置；从别的对话打开也不会串用配置。
- **持久后台生成**：开始 / 继续 / 重写都交给 WorkManager，Worker 以前台服务（dataSync）运行，锁屏或切走仍在跑；通知栏显示进度并可取消。杀进程后重新打开会接管继续，不会重复提交。
- **暂停与取消分开**：暂停会停下当前任务并标记 PAUSED，可继续；取消是终态，不会自动重跑。
- **作品版本**：每次提交写一份不可变清单（各节 revision + 规格/总纲/快照版本）。任务卡带版本号，点开按那一版阅读；旧卡打开旧版本，不会跳到最新正文。
- **章节摘要**：每章提交时生成结构化摘要（关键事件、未解决事项、教学目标覆盖），跨章上下文用它而不是上一节尾部文字。
- **早期重写**：重写第 N 章使用第 N 章之前的人物状态，不读后续章节的未来状态；改完后依赖它的下游章节自动标记为待复查。
- **资料检索**：长资料按相关性分块，不再只取每份前 4000 字；4000 字之后的内容也能进入请求。
- **启动不再自动播放开屏动画**：它改回彩蛋，在设置页连击版本号 5 下重放。
- **结果回写**：生成结束即在来源对话留下任务卡，卡片结构化保存（不再靠正文里的文本标记授权打开）。

## 修复的

- 系统返回键改为逐级退出：阅读器 → 总览 → 列表 → 对话，不再一按就退出应用。
- 仓库加统一锁、事务失败回滚、损坏存档改名留档；同 factId 跨项目不再互相覆盖。
- 聊天写入串行化，并在界面保存时与磁盘合并，后台投递的结果卡不会被整份写回抹掉。
- 未注册的人物、未知事件、过期的输入版本与过期执行者都不能提交。

## 已知限制

- 后台依赖 Android 的前台服务与 WorkManager；系统强制停止应用后，需要重新打开应用才会继续，不会自动绕过厂商限制。
- 角色视角下作品全文检索是**保守拒绝**的：正文没有逐句可见范围，宁可不给。
- 任务卡的进度只显示开始与结束两种状态，中途进度仍在项目内查看。
- 未关联来源对话的旧项目需要在项目里重新关联后才能自动生成。

**单元测试**：课堂领域 291 项、应用 36 项全部通过；Debug 构建成功。
