# AI-Classroom 4.0.2（正式版）

插件收口 + 触感反馈修通。版本号 `43 / 4.0.2`。

> 4.0.1 已是历史版本，保留可下载；推荐使用本版。

## 修复：小米等机型完全没有震动

**现象**：vivo 正常，小米一点反应都没有。

**根因**（dumpsys 抓到的证据）：
```
effect | ignored_unsupported | duration: 3ms | usage: TOUCH | com.aiclassroom.app
```
小米的振动 HAL 把应用**直接调用** `vibrator.vibrate()` 的请求判定为不支持并丢弃，
`Composition` 基元和 `createPredefined` 预置效果都一样被丢。

**改法**：改走系统触感通道 `View.performHapticFeedback()`，由 ViewRootImpl 转给厂商自己的
触感实现，各 ROM 都认；只有它失败时才退回直接震动。

**验证**（小米 M2007J3SC）：改前 `ignored_unsupported` 3ms → 改后 `finished` 77ms。

## 插件

默认只保留四个功能件：**沉浸模式 / 音乐 / 夜梦画室（生图配置）/ 时间流动**。
回复徽章、宠物猫两个测试件下线，老设备升级时自动清理残留目录。

## 触感反馈

- 设置里滑条调档：关闭 / 轻 / 中 / 强 / 极大，滑到哪档就用哪档强度震一次。
- 点按给完整一记；滚动列表全程安静；拖底栏换位、拖滑条每跨一格震一下。

## 按下动效

- 按钮按下时从中心渗出一圈高亮，松手弹簧回弹（带轻微过冲）。
- 已覆盖：顶栏菜单/设置、输入栏图片/发送、悬浮全屏键、回到顶部键。

## 输入框

- 平时只占一行，点进去编辑时才两行，点别处自动缩回。
- 模型与推理合并成一个键，和发送键同一条中心线。

## 音乐

- 第一次点音乐按钮若还没给「通知使用权」，直接弹窗说明并给直达按钮。

## 安装

- Android 8.0（API 26）及以上
- 签名与 4.0.0 / 4.0.1 / 3.3.5 一致，可直接覆盖安装，数据保留
