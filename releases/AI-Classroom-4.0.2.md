# AI-Classroom 4.0.2（正式版）

默认插件收口：只保留四个功能件，测试件全部下线。版本号 `43 / 4.0.2`。

> 取代 4.0.1。4.0.1 误把两个测试插件打进了安装包。

## 插件

| 保留 | 作用 |
| --- | --- |
| 沉浸模式 | 全屏风景 / 息屏像素钟 / 音乐三种形态 |
| 音乐 | 三态悬浮窗，读系统正在播放并控制播放 |
| 夜梦画室 | 生图配置 |
| 时间流动 | 把宿主时间推进并补进提示词 |

**下线**：回复徽章、宠物猫（开发期的展示演示，不是应用功能）。

老设备升级时会自动清理这两个的残留目录 —— 只从安装包里删掉不够，
已经释放到设备上的文件夹会一直留在插件列表里。

## 触感反馈

- 设置里滑条调档：关闭 / 轻 / 中 / 强 / 极大，滑到哪档就用哪档强度震一次。
- 改用系统调校过的震动基元，线性马达上是干脆的一下，不是嗡嗡的转子感。
- 点按完整一记；滚动列表全程安静；拖底栏换位、拖滑条每跨一格震一下。

## 输入框

- 平时只占一行，点进去编辑时才两行，点别处自动缩回。
- 模型与推理合并成一个键，和发送键同一条中心线。

## 音乐

- 第一次点音乐按钮若还没给「通知使用权」，直接弹窗说明并给直达按钮。

## 全屏键

- 右上角悬浮键改为圆形，样式与「回到顶部」按钮一致。

## 安装

- Android 8.0（API 26）及以上
- 与 4.0.0 / 4.0.1 / 3.3.5 签名一致，可直接覆盖安装，数据保留
