# AI-Classroom 4.0.0

一次大版本收尾：代码结构重整、插件体系收口、网页工具补齐，外加一版像素开屏动画。版本号 `41 / 4.0.0`。

---

## 开屏动画

首次启动会播放一段像素动画：3.0 时代的紫蓝「3」消散，4.0 的红色「4」从四周重组，收进方框地球后变形为「NEW」，然后停在 NEW 上等你点击。

- 安装新版本后的**第一次启动**播放；点屏幕任意位置可跳过
- 设置页底部连击版本号 5 下可以重放

## 插件

| 变化 | 说明 |
| --- | --- |
| 数字设置项改为滑条 | 拖动即时生效，不用保存再重启 |
| 沉浸模式 / 音乐改为系统插件 | 列在「内置功能」组，可以停用，不能卸载 |
| 示例插件单独分组 | 夜梦画室、宠物猫等演示件归到「示例插件」，可直接卸载 |
| 顶栏按钮改为纯图标 | 沉浸、音乐、设置三个同尺寸图标 |

## 音乐

- 时间条彻底重写：酷狗这类播放器在播放时 `position` 恒为 0，现在由应用按流逝时间推算，不再跳变也不会归零
- 换了首歌正确重置；暂停时停在当前位置而不是跳回 0:00
- 悬浮窗可在设置里调大小；小圆与大浮窗互斥切换，位置共享

## 网页工具

| 工具 | 新能力 |
| --- | --- |
| `web_capture` | 新增 `clipX/clipY/clipW/clipH`，只截指定区域 |
| `web_act` | 新增 `js` 动作，可执行脚本（例如把视频 seek 到某一秒）|
| `web_allow_domain` | 新增，在对话里直接放行站点，不用去设置手填域名 |

遇到需要登录的页面时，AI 会截图 → 只裁二维码那一块 → 用 `send_image` 发给你扫。

## 修复

- **长按对话消息导致应用崩溃**（原生 SIGSEGV）：菜单原来在列表 item 里伪造全屏 + 全屏模糊，改用标准 Popup
- **请求失败的红色提示永久停留**：改为 8 秒自动收起，并带手动关闭
- **进入课堂时的滚动动画**：改为首次组合直接定位到最新一条
- **悬浮窗封面自转卡顿**：逐帧动画不再走 `Animatable.snapTo`（每帧一次互斥锁），`Paint` 按插件版本缓存避免整棵 overlay 树重组。45fps → 125fps

## 新增

- 长按菜单新增「复制」
- 设置页底部版本号：单击检查更新，连击 5 下重放开屏动画

## 代码结构

主文件 `MainActivity.kt` 从 8478 行压到 7332 行，拆出 13 个文件：

```
model/Models.kt      数据模型
util/Const.kt        常量集中
util/Palette.kt      调色板与主题
util/Text.kt         文本与 Markdown
util/Memory.kt       记忆与知识库
util/Prompt.kt       系统提示词拼装
util/Api.kt          请求构造与响应解析
util/Media.kt        媒体与本地文件
util/Chapter.kt      章节与分支
util/Misc.kt         零散工具
util/Identity.kt     课堂身份
util/Exam.kt         考试记录
util/JsonExt.kt      JSON 扩展
ui/splash/SplashCg.kt  开屏动画
ui/chat/*.kt         对话组件
```

依赖方向改为单向：`model ← util ← ui ← MainActivity`。
