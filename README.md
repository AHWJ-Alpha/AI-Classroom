# AI Classroom

一间可以持续学习、也可以一起写故事的 AI 课堂。主课堂保留长期脉络，分支课堂容纳临时探索；知识库、角色卡与世界书帮助讲师在长对话里保持设定一致。

> 当前源码版本：`3.2.0`。已发布版本及安装包以 [GitHub Releases](https://github.com/AHWJ-Alpha/AI-Classroom/releases) 页面为准。Android 最低要求：8.0（API 26）。

本文是当前版本的使用说明。历史更新日志仅描述对应版本的改动；当前功能、支持格式和使用方式以本文为准。

## 开始使用

1. 从 Releases 下载 APK 并安装。若系统提示来自未知来源，请确认下载地址后按设备提示操作。
2. 在应用设置中填写你自己的模型 Base URL、API Key 与模型名。应用使用兼容 Chat Completions 的接口；图片分析和语音朗读可分别配置。
3. 输入想学习的主题，或为小说项目新建课堂。第一轮对话后可自动生成课堂名称和一句话简介，也可以在课堂菜单中修改。

空课堂首页采用低饱和配色，保留浅色日期与中部输入框。开始对话后进入消息列表；课堂菜单用于搜索、切换和管理课堂，名称与简介可以分别编辑。

## 你可以做什么

| 场景 | 能力 |
| --- | --- |
| 持续学习 | 流式对话、深度思考模型、课堂章节与长期记忆；最近对话优先，历史摘要按需召回。 |
| 分支探索 | 从任意主课堂消息开启独立分支，保留开启时的上下文，不把分支内容写回主线。 |
| 小说创作 | 讲师人格、世界书、角色可知信息和私密设定协同；角色卡作为作者级人物参考。 |
| 资料查阅 | 导入本地知识库文件，按当前问题与对话检索相关片段；支持查看和删除已导入文件。 |
| 其他工具 | 多模型降级、图片分析、TTS 朗读、结构化考试与讲解分支。 |

### 知识库与角色卡

| 导入类型 | 支持格式 | 用途 |
| --- | --- | --- |
| 普通资料 | `.md`、`.txt` | 按问题召回相关段落，不把整库无差别塞进每次请求。 |
| 角色卡 | `.md`、`.json`、`.png` | 长期参考人物身份、性格、口吻、关系与行为边界；支持批量导入。 |

PNG 角色卡需要包含可识别的文本元数据；普通图片文件不等于角色卡。JSON 支持常见角色字段及嵌套的 `data`。导入后可在知识库中查看文件，长按删除。

角色卡、世界书与长期记忆是提供给模型的上下文，不会修改模型参数。资料检索和角色卡插入受上下文预算限制，导入文件不代表模型每轮都能看到完整原文。

## 用于小说写作

1. 为小说新建一个课堂，在讲师人格中描述叙事风格、视角与写作要求。
2. 把世界规则、时间线约束和固定设定写入世界书。
3. 通过“导入角色卡”添加主要人物，每位角色建议单独建卡。Markdown 以一级标题作为角色名，可用“身份”“性格”“语言风格”“动机”“关系”“行为边界”等小节组织内容。
4. 通过普通资料入口导入背景资料和叙事示例。提问时明确相关人物、事件或设定，有助于检索到需要的段落。
5. 在主课堂继续正文；需要探索支线时，从相关消息开启分支课堂。

### 长期记忆与人物视角

应用会整理章节摘要、常驻前提和关键词记忆卡，并按当前对话召回历史内容。世界书记忆卡记录可见性、知道者、不知道者和证据，用于提示模型区分作者信息与角色认知。

最近连续对话中的事实优先于旧摘要和设定。作者私密与角色私密内容可能作为参考进入模型上下文，提示词要求模型不要让未知角色据此行动；这属于叙事约束，不是独立模型之间的信息隔离，也不能保证模型绝不串视角。重要剧情仍需核对，发现偏差时应明确纠正事实或设定。

## 常见问题

**PNG 导入失败？** 确认文件是带角色数据的 PNG 角色卡，而非普通立绘或截图。文件扩展名正确但没有可识别的元数据时，仍无法导入为角色卡。

**上传资料后，AI 没有引用其中的内容？** 先在知识库中打开文件，确认文本已正确导入。普通资料采用轻量检索，每轮只插入部分相关片段；可以在问题中补充资料中的人物名或关键词，必要时直接提供关键原文。目前普通资料入口支持 `.md` 和 `.txt`。

**为什么没有震动反馈？** 导入、选择和删除等操作使用系统触觉反馈，实际效果取决于设备硬件与系统触觉设置。

## 数据与安装

- 课堂、对话、知识库、记忆及配置保存在设备本地。调用 AI 时，相关上下文会发送到你配置的模型服务；请自行了解该服务的数据处理政策。
- API Key 属于敏感信息。提交 Issue、日志或截图前请先遮盖密钥和私人课堂内容。
- 如果手机里安装过使用**不同证书**签名的 Debug/旧 APK，Android 无法直接覆盖安装；处理前请先妥善保留本地数据。正式安装包请以 Releases 中的文件为准。

## 本地构建

使用 Android Studio 打开项目，或在已配置 JDK 17 和 Android SDK 的 Windows 环境中运行：

```powershell
.\gradlew.bat :app:assembleDebug --no-daemon
```

生成的调试包位于 `app/build/outputs/apk/debug/app-debug.apk`。调试包使用调试证书，不应代替 Release APK 分发。发布构建需要开发者密钥；不要将 `signing/`、密码文件或 API Key 提交到仓库。

技术栈：Kotlin · Jetpack Compose · 本地 JSON 持久化 · OpenAI 兼容接口。
