# AI Classroom

AI Classroom 是一款面向长期学习场景的 Android AI 课堂 Demo。它围绕“主课堂 + 分支课堂 + 长期记忆 + 知识库”的学习模式，让用户可以在 AI 导师陪伴下持续学习一门课程，并在不打断主线的情况下展开支线探索。

当前最新版本：`2.3.2`

## 核心功能

### 主课堂

- 用户可自定义学习内容。
- 空课堂首页显示日期、星期和模型生成的短格言，输入学习要求后进入正式对话界面。
- 开课前可直接选择是否启用深度思考模型。
- AI 会围绕当前课堂持续教学。
- 支持 Markdown 和数学公式文本显示。
- 支持真实流式输出，AI 回复会边生成边显示。
- 支持在主课堂上传照片，由多模态模型分析解答。
- 双击 AI 回复可调用 TTS 朗读。
- 课堂、对话、配置、记忆和知识库均保存在本地。

### 分支课堂

- 可从主课堂任意一段对话开启分支。
- 分支是与主课堂平行的独立长对话。
- 开分支时会冻结当时的主课堂上下文。
- 分支后续内容只保存在分支内，不会复制、打包或改写主课堂。

### 长期记忆

- 后台按批次整理对话，不阻塞前台聊天。
- 自动生成章节标题和一句话摘要。
- 长对话回答优先依据最近连续对话，长期记忆和章节索引仅作为压缩参考。
- 记忆摘要会区分明确事实和待确认事项，减少模型硬编。
- 记忆页支持章节索引。
- 全览模式会生成实时向量思维导图。
- 思维导图支持双指缩放、拖动查看，双击节点可跳回主课堂对应对话。

### 知识库

- 支持直接读取 `.md` 和 `.txt` 文件。
- 文件全文会保存在本地，并作为课堂知识库上下文参与教学。
- 上传后的文件会列在知识库中，可点击查看、长按删除。

### 模型与 API 配置

- 模型模块、多模态模块、TTS 模块分别拥有自己的 Base URL、API Key 和模型配置。
- 模型模块支持多个模型按优先级自动降级。
- 支持深度思考模式，可单独配置深度思考模型。
- 多模态模块用于课堂图片分析。
- TTS 模块支持语音模型、音色配置和长时自动朗读。

### 考试模式

- 当 AI 明确输出结构化考试内容时，应用会进入沉浸式考试界面。
- 题目支持“前提 + 问题 + 答案框”的结构。
- 提交后会退出考试界面，并将答案打包给 AI 批改。
- 标记“不会”的题目会生成对应讲解分支。

### 主题和界面

- 按钮皮肤保留“二次元”和“自定义”。
- 二次元固定使用 `#39C5BB`。
- 自定义模式可通过调色盘或 Hex 输入选择一个按钮色。
- 界面明暗可自动跟随系统，也可指定白色或黑色，并保持文字反色。
- 背景、卡片和正文保持原生明暗风格，皮肤色只用于按钮和可点击强调。
- 主课堂左滑才会展开课堂菜单，其他页面不会误触。

### 课堂菜单和讲师

- 主界面使用轻量顶部占位，不再显示固定标题栏。
- 二级菜单支持搜索课堂、切换课堂、新建课堂、复制配置、删除课堂。
- 支持直接修改课堂名字。
- 讲师名字会显示在课堂消息中，用户称呼会注入提示词。

## 本地编译

使用 Android Studio 打开项目，或在项目根目录运行：

```powershell
.\gradlew.bat assembleDebug --no-daemon
```

Debug APK 输出位置：

```text
app/build/outputs/apk/debug/app-debug.apk
```

项目内归档 APK 位于：

```text
releases/
```
